# Interactive Navigation Menu

## 📌 Project Overview
This project demonstrates an interactive and responsive navigation menu built using HTML, CSS, and JavaScript. The navigation bar remains fixed at the top of the page, ensuring it is always visible while users browse the website. It also includes dynamic effects such as changing the background color when the page is scrolled and hover effects on menu items to improve user interaction.

---

## ✨ Features
- Fixed navigation bar visible on all pages
- Responsive design for different screen sizes
- Background color changes when scrolling
- Smooth hover effects on navigation links
- Clean and modern user interface
- Easy to customize and extend

## 📖 How It Works

- The navigation bar is fixed at the top of the webpage using CSS.
- JavaScript detects when the user scrolls down the page and changes the navigation bar's appearance.
- CSS hover effects highlight menu items when the mouse pointer is placed over them.
- Smooth transitions make the animations visually appealing.
